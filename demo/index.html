inkfield

A Jos Stam stable-fluids simulation rendered as drifting ASCII glyphs. Move the pointer across this band to trail ink; click for a burst.

H frame stats · B 8s benchmark · #tune sliders

Scoped to its own element

This canvas is position: absolute inside the header rather than fixed to the viewport, so it leaves with the rest of the page as you scroll. A ResizeObserver keeps the simulation grid matched to the canvas box, so the same code works as a full-bleed background or a banner like this one.

Behind the text, out of the way

The canvas is pointer-events: none, so this copy stays selectable and links keep working. Ink is only injected while the pointer is inside the canvas box, which is why the field stops responding once you scroll past the banner. 

npm install inkfield

import { createInkfield } from 'inkfield';
createInkfield();          // fixed, full-viewport, click-through

Two backends

WebGL2 draws the whole grid in one instanced call, so cost stays flat in the number of cells. Without WebGL2 it falls back to Canvas2D and blits from a glyph atlas. Press H to see which one is running and what a frame costs.

  • No dependencies, no build step, 13 kB packed
  • Respects prefers-reduced-motion
  • Recovers from WebGL context loss
  • This page is one self-contained file
