inkfield

A Jos Stam stable-fluids simulation rendered as drifting ASCII glyphs. Move the pointer anywhere on the page to trail ink; click for a burst.

H frame stats · B 8s benchmark · #tune sliders

One canvas, the height of the page

The canvas is position: absolute over the whole document rather than fixed to the viewport, so the ink scrolls with the content instead of sitting still behind it. A ResizeObserver keeps the simulation grid matched to the canvas box, which here is the full page.

Behind the text, out of the way

A CSS mask carries the ink at full strength through the banner and drops it to a wash further down, so it keeps moving behind this paragraph without competing with it. The canvas is pointer-events: none, so the copy stays selectable and links keep working while ink still follows the pointer anywhere on the page. 

npm install inkfield

import { createInkfield } from 'inkfield';
createInkfield();          // fixed, full-viewport, click-through

Two backends

WebGL2 draws the whole grid in one instanced call, so cost stays flat in the number of cells. Without WebGL2 it falls back to Canvas2D and blits from a glyph atlas. Press H to see which one is running and what a frame costs.

  • Respects prefers-reduced-motion
  • Recovers from WebGL context loss
